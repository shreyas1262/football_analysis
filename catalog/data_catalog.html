Data quality & decisions

✓ League-only, gated on schedule

Team-match tables keep a row only if its match_id exists in stg_fbref_schedule — the reliable league-fixture list.

This recovered 310 league matches a naive league != 'nan' filter had dropped: the bronze league column is unreliably 'nan' even for real league games.

⚑ NaN is a string, not NULL

Bronze stringified pandas NaN, so nulls arrive as the literal text 'nan'. Filter with != 'nan', never IS NOT NULL.

⚑ Dates from the game string

The bronze date is a tz-aware timestamp; date::date is off by one day. Match dates come from split_part(game,' ',1) instead.

✓ Cup data intentionally excluded

FBref only tracks Big-5 teams' cup games (often one-sided, with nan stats), so cup matches are left in bronze. Silver is strictly the Big-5 leagues.

Naming — reconciled ✓

Building the catalog surfaced drift between the player and team models — the same concept spelled differently across tables. It's now aligned to one vocabulary, so unions and joins in gold speak the same language. The canonical form and what was folded into it:
